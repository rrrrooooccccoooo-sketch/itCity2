# Guia de capacitacion por roles

## Objetivo

Proveer un plan de entrenamiento corto, medible y repetible para cada nivel de acceso de ITCity.

## Duracion sugerida

- Bloque 1: 30 min (conceptos y navegacion)
- Bloque 2: 45 min (practica guiada)
- Bloque 3: 15 min (evaluacion)

## Bloque 1: Conceptos comunes

1. Estructura de campus, nodos y relaciones.
2. Diferencia entre topologia, monitoreo e inventario.
3. Importancia de alcance por campus y trazabilidad.

## Bloque 2: Practicas por rol

### A) Administrador completo

Ejercicio A1: crear usuario con perfil y alcance.

1. Crear un usuario de prueba.
2. Asignar perfil operativo.
3. Limitar a un campus.
4. Validar permisos.

Ejercicio A2: ciclo completo de activo.

1. Editar activo inventariado.
2. Reasignar responsable.
3. Capturar firma de recepcion.
4. Generar responsiva y validar QR.

### B) Administrador operativo

Ejercicio B1: correccion de topologia.

1. Abrir /red.
2. Corregir etiqueta o estado de un nodo.
3. Ajustar relacion entre dos nodos.
4. Guardar layout.

Ejercicio B2: atencion de incidencia.

1. Revisar monitoreo.
2. Identificar nodo en warning/error.
3. Registrar accion correctiva.
4. Confirmar cierre.

### C) Auditor (solo lectura)

Ejercicio C1: revision de evidencia.

1. Consultar un activo en panel.
2. Abrir bitacora de asignacion.
3. Verificar campos de entrega/recepcion.
4. Registrar hallazgo.

Ejercicio C2: reporte de topologia.

1. Revisar topologia por campus.
2. Detectar inconsistencia documentada.
3. Levantar observacion formal.

## Bloque 3: Evaluacion rapida

### Criterio de aprobacion

- Puntaje minimo: 80/100
- Sin errores en reglas criticas de seguridad o alcance

### Rubrica

1. Navegacion correcta del sistema (20 pts)
2. Ejecucion del flujo del rol sin bloqueos (30 pts)
3. Comprension de permisos y limites (20 pts)
4. Calidad de evidencia/registro final (30 pts)

## Checklist del instructor

1. El usuario identifica su alcance por campus.
2. El usuario no intenta acciones fuera de su rol.
3. El usuario completa al menos un flujo de inicio a fin.
4. El usuario interpreta estados de monitoreo correctamente.
5. El usuario documenta resultados de forma clara.
